## Описание

Необходимо реализовать механики преодоления препятствий `(Vaulting)` и взбирания на уступ `(Mantling)`.

## Общие технические детали
- Вы можете выполнять задание как на `C++`, так и с помощью `Blueprints`, однако `C++` предпочтительнее.
- Механики должны быть реализованы с помощью `Gameplay Ability System`.
- Результатом работы должен стать форк этого репозитория, содержащий реализованные механики и все необходимыме ассеты для тестирования разработанного решения, а также видео демонстрацию полученного результата.

## Vaulting
- Попытка преодолеть препятствие происходит по нажатию клавиши. 
- Игрок может преодолевать только определенные препятствия. Вы можете самостоятельно решить способ их обнаружения и идентификации. Если игрок хочет преодолеть препятствие, не отмеченное разработчиком - ничего не происходит.
- Анимация должна выбираться в зависимости от характеристик преодолеваемого препятствия (высота) и характеристик персонажа игрока (скорость).

## Mantling
- Попытка взобраться на уступ происходит по нажатию клавиши. 
- Игрок может взбираться только на определенные уступы. Вы можете самостоятельно решить способ их обнаружения и идентификации. Если игрок хочет взобраться на уступ, не отмеченный разработчиком - ничего не происходит.
- Анимация должна выбираться в зависимости от характеристик уступа (высота).

## Анимации
Все необходимые анимации для выполнения этого задания можно найти внутри проекта по пути `/All/Game/Characters/Mannequins/Animations/Manny`.

## Критерии оценки
- Работоспособность механики `Vaulting`;
- Работоспособность механики `Mantling`;
- Возможности разработанного решения к настройке;
- Качество кода;
- Скорость выполнения.
 
## Дополнительно
Вы также можете предоставить текстовое описание реализации данной механики, если у Вас нет возможности выполнить полную реализацию в установленные сроки или у Вас есть идеи для улучшения, требующие значительного времени на разработку.
